Taruh file lagu MP3 favoritmu di folder ini dan beri nama:

  lagu.mp3

Contoh lokasi akhir:
  C:\Users\Lenovo\birthday-website\music\lagu.mp3

Jika file lagu.mp3 tersedia, piringan vinyl di website akan otomatis memutar lagu tersebut saat panah Cupid mengenai hati!
Jika belum ada file lagu.mp3, website otomatis memutar melodi kotak musik "Happy Birthday" yang lembut.
